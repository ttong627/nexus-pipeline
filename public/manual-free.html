STEP 1

🚀 시작하기

접속 후 두 가지 방법 중 하나를 고릅니다.

logis-op.web.app — 로그인 화면

① 빠르게 체험만 → “로그인 없이 무료로 정제하기” · ② 저장까지 쓰려면 → “Google 계정으로 시작” (무료 가입)

추천: 처음이라면 “로그인 없이 무료로 정제하기”로 바로 체험해 보세요. 마음에 들면 그때 무료 가입해도 작업 내용이 유지됩니다.
STEP 2

📁 엑셀 파일 올리기

정제할 명단 파일을 화면에 끌어다 놓거나 클릭해서 선택합니다.

명단 정제 시작하기

파일을 끌어다 놓으면 전체 시트를 자동 분석해 진짜 명단만 골라냅니다. 왼쪽 메뉴에서 사용 가이드도 언제든 열 수 있습니다.

지원 형식

  • .xlsx / .xls — 엑셀 파일
  • .csv — 쉼표로 구분된 텍스트 파일
  • 여러 파일을 한 번에 올려도 됩니다

업로드 후 — 지자체·월 확인

파일을 올리면 프로그램이 지자체와 월을 자동으로 감지합니다. 맞는지 확인하고 넘어가세요.

지자체 · 적용 월 확인

예시에서는 주소를 보고 경기도 시흥시 · 2026-06을 자동으로 감지했습니다.

STEP 3

⚙️ 정제 방식 — “쉬운 정제”면 끝

대부분은 쉬운 정제면 충분합니다. 칼럼이 자동으로 맞춰졌는지 확인하고 정제 시작만 누르면 됩니다.

쉬운 정제 — 확인만 하면 끝!

총 10명 · 칼럼 자동 매칭 완료가 보이면 “정제 시작”을 누르세요. 직접 조정하려면 “직접 매핑(고급)”.

고급 정제를 고르면 시트 선택과 컬럼 매핑(이름·주소·연락처·행정동·포수)을 직접 확인·수정할 수 있습니다. 틀린 칸만 드롭다운으로 바꾸면 됩니다.
STEP 4

🔍 정제 결과 확인하기

잠깐 기다리면 주소가 표준 도로명주소로 정리된 표가 나옵니다.

정제 결과

주소가 도로명주소 + 동·호수 + (법정동, 건물명) 형식으로 정리됩니다. 표의 칸을 클릭하면 바로 고칠 수 있습니다.

직접 수정도 가능

  • 표의 칸을 클릭하면 바로 고칠 수 있습니다
  • 확인필요로 표시된 줄은 원본 주소가 불완전한 경우이니 한 번 봐주세요 (위 예시에서는 10명 중 9명 정상, 1명 확인필요)
  • 실수했다면 되돌리기(Ctrl+Z)로 이전 상태로 복원됩니다
자동으로 해주는 것: 이름 5자 초과 정리 · 오타 교정 · 통/반 제거 · 동·호수 형식 통일 · 전화번호 형식 정리 · 특수문자 뒤 내용을 특이사항으로 분리 — 손댈 필요 없이 알아서 정리됩니다.
STEP 5

⬇️ 엑셀로 다운로드

정제가 끝나면 결과 화면 오른쪽 위 “엑셀 다운로드” 버튼으로 바로 받을 수 있습니다. 무료에서도 다운로드는 자유롭게 됩니다.

결과 화면 — 엑셀 다운로드

상단 툴바의 “명단 다운로드 / 엑셀 다운로드”를 누르면 됩니다. [확인필요]만, [행정동요약] 형태로도 받을 수 있습니다.

파일명은 지자체-N월-기초N,차상위M,전체T-날짜시간.xlsx 형식으로 자동 생성됩니다.

여기까지가 게스트(비로그인) 무료 범위입니다. 정제 결과를 클라우드에 저장하거나 매달 이어서 작업하려면 아래 무료 회원가입이 필요합니다.
STEP 6 · 무료 회원

🎁 무료 회원가입하면 더 열리는 것

Google 계정으로 무료 가입(일반 등급)하면 정제·다운로드에 더해 다음이 가능합니다. 요금 없이 쓸 수 있는 일반 등급 기능입니다.

  • 이번달 배송명단 저장/조회 — 정제 결과를 클라우드에 저장하고 언제든 다시 엽니다
  • 고객 노트(특이사항) 저장·이식 — “부재 시 경비실”처럼 자주 쓰는 메모를 저장해 다음 달에 자동으로 붙입니다
  • 부가 서비스 — 중복 명단 분석 등 정리 도구
  • 지자체 1개 관리 · 지자체당 월 1만 건 처리
참고: 일반(무료) 등급은 좌표 매칭·기사 배정·루트맵은 포함하지 않습니다. 이 기능들은 유료(VIP 이상)입니다. 아래 비교표를 보세요.

FAQ

❓ 자주 묻는 질문

로그인 없이 정말 무료로 쓸 수 있나요?
네. ‘로그인 없이 무료로 정제하기’를 누르면 가입·결제 없이 주소 정제와 엑셀 다운로드를 바로 쓸 수 있습니다. 다만 저장 기능은 무료 회원가입이 필요합니다.
내 명단 데이터는 안전한가요?
게스트 모드에서는 데이터가 서버에 저장되지 않고 브라우저에서만 처리됩니다. 저장 기능을 쓰려면 로그인해야 하며, 본인 계정의 데이터만 접근됩니다.
정제가 이상하게 된 주소가 있어요.
표에서 해당 칸을 클릭해 직접 고칠 수 있습니다. ‘확인필요’로 표시된 줄은 원본 주소 자체가 불완전한 경우가 많으니 원본을 확인해 주세요. Enter로 재정제하면 오타는 자동 학습됩니다.
여러 지자체 명단을 쓰고 싶어요.
일반(무료) 등급은 지자체 1개입니다. 여러 지자체가 필요하면 VIP(5개)·VVIP(20개)·사파이어(무제한)로 업그레이드하세요. 앱의 ‘회원등급’ 메뉴에서 문의할 수 있습니다.
기사 배정·배송 지도는 무료로 안 되나요?
좌표 매칭·기사 배정·루트맵은 VIP 이상 유료 기능입니다. 자세한 사용법은 유료 사용 가이드를 참고하세요.
