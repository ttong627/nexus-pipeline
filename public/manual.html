OVERVIEW
프로그램 소개
🎯 핵심 목적
지자체별 복지 배송 명단(엑셀)을 자동으로 정제하여 도로명주소로 변환하고, 기사별 구역을 자동 배분합니다. 기본명단 DB와 비교해 신규·변경 데이터를 관리합니다.
👥 사용 대상
복지 배송을 담당하는 지자체 담당자 및 배송 운영자. 관리자는 전체 지자체를 제어하고, 일반 사용자는 승인된 지자체만 접근 가능합니다.
⚡ 자동 주소 변환
도로명주소 API 3개 키를 로테이션하며 14가지 정제 규칙을 적용합니다. 오타 자동 수정, 지역 접두어 제거, 동호 정규화까지 자동 처리됩니다.
🗄 클라우드 DB
Google Firestore에 지자체·월별로 저장됩니다. 기본명단(영구 데이터)과 클라우드 명단(월별 데이터)을 분리 관리합니다.
🗺 기사 자동 배분
동적 가중 보로노이 K-means++ 알고리즘으로 기사 구역을 자동 분할합니다. capacity 비례 포수 배분과 지리적 구역 분리를 보장합니다.
💡 팁 처음 사용하는 경우 1단계(엑셀 업로드)부터 순서대로 진행하세요. 대시보드에서 지자체를 클릭하면 해당 데이터를 바로 열 수 있습니다.

7-STEP PIPELINE
파이프라인 전체 흐름
1
📁 엑셀 파일 업로드
지자체에서 받은 엑셀(xlsx/xls/csv) 파일을 드래그&드롭 또는 클릭으로 업로드합니다. 파일 크기, 시트 수 자동 확인.
xlsx 지원 xls 지원 csv 지원
2
📋 시트 선택
여러 시트가 있는 경우 처리할 시트를 선택합니다. 수급자/차상위 시트를 개별 또는 통합 처리 가능.
다중 시트 자동 유형 감지
3
🔗 컬럼 매핑
엑셀의 컬럼을 이름·주소·포수·연락처 등 내부 필드에 매핑합니다. 헤더 자동 감지로 대부분 자동 완성됩니다.
헤더 자동 감지 수동 조정
4
🔧 주소 자동 정제 (AI 엔진)
14가지 규칙으로 주소를 정제하고 도로명주소 API로 변환합니다. 500건씩 병렬 처리하여 대용량도 빠릅니다.
asyncPool(20) API 3키 로테이션 캐시 2단계
5
🔍 결과 검토 & 수동 수정
정제 결과를 그리드에서 확인하고 오류 주소를 수동으로 수정합니다. 필터, 정렬, 검색으로 빠르게 찾을 수 있습니다.
오류 필터 셀 직접 편집 재정제 (Enter)
6
💾 DB 저장
정제 완료 데이터를 클라우드 DB에 저장합니다. 기본명단과 비교하여 변경사항을 이식하고 감사 로그를 기록합니다.
499건 배치 3순위 매칭 감사 로그
7
🗺 루트맵 — 기사 자동 배분
저장된 명단의 좌표를 기반으로 기사 구역을 자동 배분합니다. K-means++ 알고리즘과 수동 조정 도구를 함께 제공합니다.
보로노이 K-means++ 페인트 브러시 공유 링크

STEP 1
엑셀 파일 업로드
업로드 방법
  • 대시보드 중앙의 드래그&드롭 영역에 파일을 끌어다 놓기
  • 영역을 클릭해서 파일 탐색기로 선택
  • 헤더 바의 + 업로드 버튼 클릭
지원 파일 형식
  • .xlsx — Excel 2007 이상 (권장)
  • .xls — Excel 97-2003
  • .csv — 쉼표 구분 텍스트
⚠️ 업로드 전 확인사항
  • 파일에 헤더(컬럼명) 행이 있어야 합니다
  • 이름·주소 컬럼이 반드시 포함되어야 합니다
  • 셀 병합이 심한 경우 자동 감지가 어려울 수 있습니다
  • 파일 크기 제한은 없으나 10,000건 이하 권장
💡 팁 Web Worker로 처리되어 업로드 중에도 화면이 멈추지 않습니다.
📋
STEP 2
시트 선택
시트 선택 규칙
  • 시트가 1개면 자동으로 다음 단계로 진행됩니다
  • 여러 시트 중 처리할 시트에 체크박스 선택
  • 복수 시트 선택 시 합쳐서 처리됩니다
시트 유형 자동 감지
시트명 키워드감지 유형
수급, 의료, 생계기초수급자
차상위차상위계층
기타 (구분 컬럼으로 자동 감지)혼합 시트
💡 혼합 시트 처리 '구분', '유형', '계층', '자격' 컬럼이 있으면 데이터 값을 분석해 기초수급자/차상위를 자동으로 분류합니다.
⚠️ 주의 같은 파일에서 여러 시트를 선택할 때 동일한 수급자가 중복될 수 있습니다. 최종 저장 전 중복 분석 기능을 사용하세요.

자동 매핑이 잘못된 경우 드롭다운으로 직접 지정할 수 있습니다. 이름과 주소는 반드시 매핑되어야 합니다.

STEP 4 — AI ENGINE
주소 자동 정제
⚡ 처리 방식 20개 병렬 스트림 × 500건 청크로 처리. 메모리 캐시(1000건) + IndexedDB 2단계 캐시로 이미 처리된 주소는 API 없이 즉시 반환합니다.
정제 엔진 실행 순서
①
유니코드 정규화 (NFC)
제어문자, NBSP, 탭, 개행 제거. 따옴표 제거. 미닫힌 괄호 삭제.
②
오타 사전 치환
Firestore typo_dict에 등록된 오타를 자동 치환. Enter 재정제 시 새 오타 자동 학습.
③
특수문자 분리
* / ☆ ★ | ~ # 이후 내용을 특이사항으로 이동. special_chars DB 자동 확장.
④
지역 접두어 & 통·반 제거
시/도/구/동 토큰 제거. 제X통 제X반 패턴 삭제.
⑤
도로명주소 API 호출
3개 API 키 로테이션. 캐시 미스 시에만 호출. 실패 시 4단계 검색어 전략 적용.
⑥
동호 형식 정규화
XXX동 YYY호 Z층 → XXX-YYY호 Z층으로 통일.
⑦
최종 포맷 조합
도로명주소, 상세주소 (동명, 건물명) 형식으로 완성.
주소 정제 14가지 규칙 상세
#규칙명내용
A-1이름 5자 초과5자로 자르고 (본명:XXX)를 특이사항에 추가
A-2오타 사전Firestore typo_dict 우선 치환 (AI 자가학습)
A-3유니코드 정규화NFC + 제어문자/NBSP/탭/개행 제거
A-4미닫힌 괄호 제거\([^)]*$ 패턴 삭제
A-5지역 접두어 제거시/도/구/동 토큰 — 도로명·지번 만나면 제거 중단
A-6통·반 제거제X통 제X반 패턴 제거
A-7주민센터 검색어①행정동 컬럼 > ②분리형 > ③부착형 > ④시군구+주민센터
A-8건물명 Fallback도로명·지번 없고 건물 유형어 있으면 adminDong + 건물명으로 재검색
A-9특수문자 분리* / ☆ ★ | ~ # 이후 내용 → 특이사항 이동
A-10동호 형식 정규화XXX동 YYY호 Z층 → XXX-YYY호 Z층
A-11최종 주소 형식도로명주소, 상세주소 (동명, 건물명)
A-12확인필요 플래그주소 공란 / API 실패 / 변환 후 3자 미만
A-13API 캐시메모리(1000건) + IndexedDB 2단계, 중복 요청 dedup
A-14병렬 처리asyncPool(20) — 500건 청크, 50건마다 메인스레드 양보
⚠️ 처리 중 화면 이탈 주의 정제 중 새로고침하면 진행 상황이 초기화됩니다. 진행률 바가 100%가 될 때까지 기다려 주세요.

STEP 6
DB 저장
저장 대상
  • 정상 _에러 플래그 없는 행만 저장
  • 오류 행은 저장 제외 — 먼저 수정 후 저장 권장
저장 경로
월별 클라우드 명단:
cloud_lists/{city}/months/{YYYY-MM}/records/{recordId}

기본명단:
base_lists/{city}/records/{recordId}
3순위 매칭 시스템
기본명단 연결 규칙 기존 기본명단과 연결하여 기사·배송순번·특이사항을 자동 이식합니다.
순위매칭 기준대상
1순위이름 + 생년월일전체 레코드
2순위이름 + 휴대폰생년월일 없는 레코드
3순위이름 + 유선전화생년월일·휴대폰 모두 없는 레코드
⚠️ 동월 데이터 존재 시 같은 월 데이터가 이미 있으면 확인 팝업이 나타납니다. 확인 시 기존 데이터 전체 삭제 후 재저장됩니다.

1

저장된 주소로 좌표(lat, lng)를 가져옵니다. 좌표가 없으면 자동 배분 버튼이 잠깁니다.
2
기사 핀 배치 (선택)
기사 카드의 [핀 꽂기]를 클릭 후 지도에서 기사 거점을 클릭합니다.
3
자동 N등분 실행
동적 가중 보로노이 K-means++가 capacity 비례로 구역을 자동 분할합니다.
4
수동 보정 (선택)
페인트 브러시 모드로 드래그하여 구역을 수동 조정합니다.
5
겹침 확인 후 최종 저장
동선 겹침 0건 확인 후 저장. 기사별 공유 링크 생성 가능.

FAQ
자주 묻는 질문
Q. 주소가 계속 "확인필요"로 표시됩니다.
A. 주소 셀을 더블클릭해서 정확한 도로명 또는 지번 주소로 수정한 후 Enter를 누르세요. 건물명만 있는 경우(예: "행복빌라") 행정동을 앞에 추가하면 API가 찾기 쉽습니다.
Q. 기본명단 이식이 안 됩니다.
A. 이식은 이름+생년월일 → 이름+휴대폰 → 이름+유선전화 순서로 매칭합니다. 세 가지 식별 정보가 모두 없으면 저장 자체가 불가합니다. 엑셀에 생년월일 또는 연락처가 있는지 확인하세요.
Q. 루트맵에서 자동 배분 버튼이 비활성화됩니다.
A. 좌표가 없는 레코드가 있으면 버튼이 잠깁니다. [좌표 매칭 실행] 버튼을 먼저 클릭하세요. 그래도 좌표를 못 찾은 건은 같은 행정동 최다배정 기사에게 자동 귀속됩니다.
Q. 담당 지자체를 추가하고 싶습니다.
A. 메뉴 → 프로필 설정에서 지자체 신청을 합니다. 관리자가 승인하면 해당 지자체 데이터에 접근 가능합니다. 현재 요금제의 지자체 한도를 초과하면 요금제 업그레이드가 필요합니다.
Q. 배송일정에서 기사를 찾을 수 없습니다.
A. 배송일정 기사는 내 기사 목록과 소속사 기사 목록을 통합하여 표시합니다. 메뉴 → 소속사 기사 관리에서 기사를 먼저 등록하거나, 프로필에서 소속사(orgId)를 설정하면 소속사 기사 목록을 가져올 수 있습니다.
Q. 엑셀을 올렸는데 컬럼이 전혀 매핑이 안 됩니다.
A. 헤더 행이 1행이 아닌 경우 자동 감지가 실패할 수 있습니다. 상위 20행을 분석하여 키워드가 가장 많이 매칭되는 행을 헤더로 선택합니다. 헤더가 없거나 모두 숫자인 경우 Step 3에서 수동으로 매핑하세요.
