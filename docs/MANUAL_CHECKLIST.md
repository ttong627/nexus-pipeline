# 수동 확인 체크리스트 — 루트맵·명단 화면

> 2026-08-23 점검에서 드러난 사실: **이 화면들을 지키는 자동 테스트가 사실상 없다.**
> `checkJs:false` 라 `.jsx` 는 타입검사를 안 받고, 스모크 테스트(28줄)는 로그인을 안 해 루트맵에 **도달조차 못 한다**.
> 그래서 지도·명단 화면을 건드린 단계마다 아래를 **눈으로** 확인한다. 자동 검증이 대신해 줄 수 없는 항목만 남겼다.

## 언제 돌리나

- `src/components/RouteMapModal.jsx` 또는 `src/components/routeMap/**` 를 고친 뒤
- `src/App.jsx` 정제·저장 경로를 고친 뒤
- 파일 분할·성능 작업 **각 단계마다**(단계를 몰아서 확인하면 어느 단계가 깼는지 못 찾는다)

## 눈으로 볼 8가지

| # | 확인할 것 | 깨졌을 때 증상 |
|---|---|---|
| 1 | **지도 진입** — 핀이 기사 색으로 뜨고, 포수 2↑ 핀이 크고, 이름·N포·동 라벨이 보인다 | 핀이 전부 같은 색·라벨 없음 |
| 2 | **브러시 드래그** — 칠한 범위의 핀 색이 즉시 바뀌고, 손을 떼면 그 배정이 유지된다 | 색만 바뀌고 저장 안 됨 / 화면 밖 레코드가 배정 안 됨 |
| 3 | **[자동 N등분]** — 실행 후 기사별 포수와 겹침(혼재) 수치가 표시된다 | 겹침이 항상 0 또는 계산 멈춤 |
| 4 | **[순번]** — 재계산 후 순번 배지가 1부터 붙고 분석 카드(총거리·평균)가 갱신된다 | 배지 안 붙음 / 카드 빈값 |
| 5 | **기사 공유 링크** — 생성 시 **암호 6자리 입력창**이 뜨고, 만든 뒤 번호가 보인다 | 암호창 없이 생성됨(SH-1 위반) |
| 6 | **세션 저장 → 재진입** — 기사 구성·배정·순번이 복원된다 | 배정이 날아감 |
| 7 | **동 큐 이동** — 미저장 변경이 있으면 확인 모달이 뜬다 | 경고 없이 이동해 변경 소실 |
| 8 | **Esc** — 전체지도(mapfull)에서 빠져나온다 · 모달이 순서대로 닫힌다 | 갇힘 |

## 명단 화면(같이 고쳤을 때만)

| # | 확인할 것 |
|---|---|
| 9 | 기본명단 **검색** — 8만 건에서도 타이핑이 끊기지 않는다(2026-08-23 이전엔 9초 멈춤) |
| 10 | 이번달 명단 **좌표 매칭** — 진행률이 오르고 끝나면 좌표 채워진 건수가 나온다 |
| 11 | 명단 업로드 → 정제 → **저장** — 건수·포수가 원본과 같다(M-1) |

## 기록

각 단계 커밋 메시지에 **"체크리스트 1~8 확인"** 또는 확인하지 못한 항목을 남긴다.
확인하지 않았으면 "확인 안 함"이라고 적는다 — 안 적으면 다음 사람이 확인된 줄 안다.
